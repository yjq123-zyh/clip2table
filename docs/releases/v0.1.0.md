clip2table 的首个公开版本：将网页、Windows 桌面应用和剪贴板中的可复制内容转换为结构化表格。

## 主要功能

- HTTP 直连、浏览器 CDP 真按键复制、Windows 桌面 SendInput 三条采集通道。
- 自动识别表格、周期记录、键值对和编号列表，展示推断依据与结构歧义。
- TOML 规则卡片，内置 5 张卡片及对应样本。
- 分页采集、页级持久化、按渠道处理续采、去重及冲突记录。
- 字段溯源、未识别内容保留和结构偏离提示。
- 导出 CSV、XLSX、JSONL 和 Markdown；超长值可通过配套文件保留。

## 环境要求

- Windows 10/11。
- Python 3.11 或以上版本。
- 零必需第三方运行时依赖。
- 浏览器采集需要启用远程调试端口，操作方法见使用说明。

## 安装

安装本次发布的 Python wheel：

```powershell
python -m pip install https://github.com/yjq123-zyh/clip2table/releases/download/v0.1.0/clip2table-0.1.0-py3-none-any.whl
```

也可以下载下方的 wheel 后本地安装：

```powershell
python -m pip install .\clip2table-0.1.0-py3-none-any.whl
```

首次使用：

```powershell
clip2table doctor
clip2table infer
```

复制需要处理的文本后运行 `infer`，即可查看结构推断结果。

## 下载文件

- `clip2table-0.1.0-py3-none-any.whl`：Python 安装包；本项目的完整采集功能面向 Windows。
- `clip2table-0.1.0.tar.gz`：Python 源码分发包。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。
- GitHub 自动提供的 Source code：本次版本标签对应的仓库源码。

## 使用边界

- 图片和 Canvas 内无法复制的文字不在采集范围内。
- 浏览器最小化时，采集可能短暂恢复窗口并借用前台焦点。
- 纯文本结构识别使用启发式规则，页面布局变化后应根据报告调整卡片。
- 本次提供 Python 包，不包含独立的 Windows EXE 安装程序。
