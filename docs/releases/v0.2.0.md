# clip2table v0.2.0

从样本生成可重复执行的采集任务，预览字段来源，修正规则并记录确认结果。

- 任务向导配置通道、目标、翻页、字段和复合去重键。
- `task check --pick N --write` 保存候选分段；`--confirm` 记录当前规则和样本的人工确认。
- 原文行号与示例值可用于标记记录边界和字段位置；修正应用于整批样本。
- 保存规则时保留正则、类型换算、复合主键及冲突策略，并核对重新加载后的解析结果。
- HTML 表格规则保留表格外文字为未识别内容；浏览器页码模板支持逐页导航。
- 任务记录显示首次配置至确认耗时、修正次数、运行耗时与成功重跑次数。
- 订单台账场景提供本地两页 HTTP 服务、独立答案和重复执行示例。

用法见 [任务操作说明](https://github.com/yjq123-zyh/clip2table/blob/v0.2.0/docs/usage.md) 和
[订单台账示例](https://github.com/yjq123-zyh/clip2table/tree/v0.2.0/scenes/order-ledger)。

浏览器与桌面采集沿用现有环境配置。旧卡可继续使用，含 `periodic` 分段的新卡需要 v0.2.0。

验证：539 项测试通过。订单场景经本地 HTTP 两页采集与二次执行，两份 CSV 均与 11 条订单的独立答案一致；浏览器导航使用模拟 CDP 测试。
