# v0.4.0

从 JSON 和 HTML 重复容器提取数据，使用增量存储持续维护台账。

- 统一单次采集、分页和恢复的会话生命周期，浏览器等待页面及目标区域就绪。
- schema 2 卡片支持 JSON 数组、相对字段路径、DOM 区域、记录选择器和属性取值。
- 预览结构候选，保存选区规则；程序动作绑定原快照与冻结规则，回答后继续原运行。
- 保存字段来源位置、覆盖统计和 JSON 数值原始文本，支持离线重算、版本比较与导出。
- 布局 3 使用逐页事件、修订增量与摊还快照；SQLite 索引更新受影响实体并支持重建。
- 台账分页查询，CSV、XLSX、JSONL、Markdown 流式导出；summary 响应保存统计和伴随文件引用。
- 布局 2 数据可整体采用到独立目录，保留请求回执、运行恢复、人工决定及未完成导出。
- 安装包内置订单台账、公告列表两套场景，包含规则、输入和独立答案。

```powershell
python -m pip install --upgrade clip2table==0.4.0
clip2table test scene:order-ledger
clip2table test scene:notice-list
```

API 保持版本 1；读取 schema 1/2 卡片、格式 1/2 解析及已有数据目录。
使用方法见 [使用说明](../usage.md)，升级与后端条件见 [兼容说明](../compatibility.md)。
