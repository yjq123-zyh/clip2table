# clip2table v0.3.0

保存采集原文，修正规则后离线重算；重复采集持续更新业务台账，保留历史和处理进度。

## 已交付功能

- `replay` 用已保存原文生成新的解析结果，展示字段、来源行和记录边界的差异。
- `rev list/show/diff/select` 管理结果版本，确认后切换当前台账。
- `ledger` 提供当前状态、历史、变化和待处理四种视图，可导出 CSV、XLSX、JSONL 和 Markdown。
- 任务按业务时间、业务版本或声明的观察时间选择当前值；晚到旧版本进入历史，缺席记录保留已知状态。
- 独立运行保留各次观察；恢复继续原运行，使用冻结配置、已保存原文和已提交结果。
- `--request-id` 支持重复请求；`--resume` 和 `--answer` 用于继续操作及提交动作回答。
- `clip2table.api` 返回结构化状态、检查点和产物；人工选择冲突候选后持久化决定。
- 数据集写锁、选择代次和产物摘要保护版本选择及导出恢复；超长单元格完整值保存到伴随文件。
- 旧页可采用到独立目录；缺少原文或来源时间时保留已有结果和未知信息。
- 订单台账场景提供三页输入、独立答案、持续更新和三种结果表的导出示例。

## 使用

```powershell
python -m pip install --upgrade clip2table==0.3.0

clip2table task run -p orders.toml -d out/orders --yes --request-id orders-morning --json
clip2table ledger -d out/orders --view current -f xlsx -o out/current.xlsx
clip2table ledger -d out/orders --view changes --baseline v-baseline
clip2table replay -d out/orders -p edited.toml --show 10
```

中断后用返回的 operation_id 或 run_id 继续：

```powershell
clip2table task run -d out/orders --resume run-xxxx --request-id orders-continue --json
```

完整用法见[使用说明](https://github.com/yjq123-zyh/clip2table/blob/v0.3.0/docs/usage.md)和[订单台账示例](https://github.com/yjq123-zyh/clip2table/tree/v0.3.0/scenes/order-ledger)。

## 兼容与验证

需要 Windows 和 Python 3.11+，运行时使用标准库。旧 TOML 卡片与旧数据集读取路径保留；新建数据集采用捕获、解析和累计结果版本布局。

666 项测试通过，覆盖重复运行、重启恢复、失败重算、动作回答、写锁、旧页兼容和导出。持续采集使用本地真实 HTTP 服务验证，浏览器导航使用模拟 CDP 客户端验证。
